# Точные границы относительного прироста

`damage_lab.relative.relative(model, graph, upgrade)` — отдельное библиотечное
ядро сравнения двух состояний произведения множителей. Оно использует точные
`fractions.Fraction` и вычисляет относительное отношение, когда общие неизвестные
множители можно обоснованно сократить. Это ещё не автоматическая рекомендация
замены предмета для импортированного Carino.

Входы — утверждения вызывающей программы: форма произведения, зависимости,
активация, интервалы и ссылки на доказательства. Проверка структуры ссылки
не подтверждает её содержание или применимость игровой формулы. Импортёр
не создаёт эти доказательства из совпадения показателей панели.

## Правила

Модель содержит `form=product`, `proof={ref}`, список `factors` и контекст
`{baseline, quantity, target}`. Замена задаёт `id` и непустой `changes` типа
`frozenset`; граф содержит направленные пары `edges` и признак `complete`.
Каждый множитель имеет точную схему:

```python
{
    'name': 'factor:q',
    'dependsOn': frozenset({'gear:q'}),  # None, если зависимости неизвестны
    'activation': 'always',             # также proven_same или unknown
    'old': (Fraction(9, 7), Fraction(9, 7)),  # None, если значение неизвестно
    'new': (Fraction(13, 8), Fraction(13, 8)),
    'positiveFinite': None,             # либо {'ref': ...}
    'invariance': None,                 # либо описанное ниже утверждение
    'provenance': [],                   # записи {'kind': ..., 'ref': ...}
}
```

`invariance` содержит `kind`, `ref`, `factor`, `upgrade`, `baseline`.
Для `independent_invariance_proof` три имени должны совпасть с текущим контекстом.
Для `dependency_disjoint` необходим полный граф, известные зависимости и отсутствие
пересечения с транзитивным замыканием изменений, включая начальные переменные.
Этот вывод опирается на объявленную полноту графа.

Сокращение также требует `positiveFinite`, активации `always` / `proven_same`
и provenance из `source_contract`, `catalog_row` или с той же ссылкой, что у
invariance. Численные интервалы применимого общего множителя должны пересекаться;
противоречащие интервалы дают отказ. Равные показанные числа сами по себе
сокращения не разрешают. Несокращённый неизвестный множитель или неизвестная
активация оставляют результат `inconclusive`.

Для каждого оставшегося множителя границы равны
`[new.low / old.high, new.high / old.low]`; их произведение даёт консервативные
границы отношения. Например, `old=[2,3]`, `new=[5/2,4]` дают `[5/6,2]`.
Общий неизвестный множитель с достаточными утверждениями сокращается; замена
другого множителя `9/7 → 13/8` тогда даёт точное отношение `91/72`.

`exact` означает точную арифметику объявленной модели; `interval` — безопасные
границы. `tight=false`: общие скрытые параметры не используются для сужения.
Удаление доказательства может расширить `exact=1` до `[2/3,3/2]`, а затем до
`inconclusive`; отказ по ресурсам или некорректным данным не является степенью
неопределённости.

## Границы реализации

До сравнений Fraction проверяются точные типы, схемы, размеры контейнеров,
строки и битовые границы. Лимиты: 64 множителя, 1024 переменные, 8192 ребра,
256 начальных изменений, 8 provenance на множитель; имена до 128, ссылки до
512 печатных ASCII-символов. Входные числители и знаменатели — до 256 бит.
Перед умножением проверяется консервативная оценка размеров результата до
12288 бит. Значения не округляются, ресурсный отказ не заменяется числом.

Результат содержит `metric`, `status`, `ratio`, `tight`, `context`, `upgrade`,
`cancelled`, `changed`, `trace`, `reasons`, `reasonsOmitted`, `limit`.
Trace сохраняет все использованные утверждения и фактические привязки;
ошибки возвращают фиксированные причины без непроверенного контекста.
Входы не изменяются. Fraction-интервалы остаются объектами Python:
JSON-сериализация, цены, ранжирование и абсолютный DPS в этот срез не входят.

У фактического частичного импорта Carino пока нет достаточных подтверждений
инвариантности, активации и полноты зависимостей. Его прирост остаётся неизвестным;
новое ядро не меняет существующие результаты расчёта и не подгоняется под манекен.
