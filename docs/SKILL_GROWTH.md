# Рост урона после уровня 20

`damage_lab.skillgrowth.multiplier(level, *, first_rate, later_rate)` — чистый математический оператор с обязательным явным выбором двух rates. Доли `.10` и `.08` означают 10% за каждый уровень 21–30 и 8% за каждый уровень 31+. До уровня 20 включительно результат равен `1.0`; это отсутствие данного дополнительного слоя, а не одинаковый базовый урон всех этих уровней.

Для L>20 вычисляется `(1+first_rate)^min(L-20,10) × (1+later_rate)^max(L-30,0)`. Оба rates валидируются до раннего возврата: только конечные неотрицательные `int`/`float`, представимые как float, без bool. Level — положительный `int`, без bool. Невалидные входы и переполнение вызывают `GrowthError`; профиль по умолчанию отсутствует.

Расчёт использует `exp(n₁·log1p(r₁) + n₂·log1p(r₂))`, чтобы малое приращение не исчезало в `1+r`. Взвешивание log выполняется через его точное бинарное отношение: огромное целое число уровней не переводится отдельно во float. Поэтому `10^320` уровней с rate `1e-320` сохраняют конечный результат. Нет цикла по уровням, игрового cap, clamp или epsilon. Результат остаётся приближением float; тесты сверяют его с независимыми Fraction/Decimal oracles, включая большие конечные результаты.

Форма оператора выведена из [Skill Level](https://tlidb.com/en/Skill_Level). Сохранённое тело описывает профиль 10%/8%; [официальная публикация The Frozen Canvas](https://torchlight.xd.com/us/news/single?id=nezvlurrIS2B) содержит 12%/10%. Это конфликт источников, а не разрешение выбрать профиль SS14. Точное происхождение сохранённых тел и ограничения разобраны в [исследовании уровней](research/help-skill-levels.md).

Оператор не определяет effective level, применимость skill tags, рост added damage/effectiveness, поддержку, minion inheritance или то, включён ли слой в другой агрегат. Он не подключён автоматически к `rawspell`, предметам или панели. Игрок не должен вручную переписывать параметры персонажа: выбор актуальной версии и автоматическое восстановление effective level остаются задачами импортёра.

Проверка: `python -m unittest discover -s tests -p test_skillgrowth.py -v`.
