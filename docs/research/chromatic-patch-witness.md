# Chromatic Shot: происхождение двух вариантов SS14

Проверено 23 октября 2026 года. Это свидетельства опубликованных данных;
применимость к сохранённому персонажу и его effective level остаются неизвестными.

## Официальное дополнение

Один сохранённый HTTP-ответ [официальной страницы SS14](https://torchlight.xd.com/ss14pn/?lang=en)
содержит дополнение от 14 октября. Китайский текст расположен в самом HTML;
английский перевод — во встроенном словаре страницы. Раздел Chromatic Shot
находится внутри дополнения, перед основной частью заметок.

| Поле | Наблюдение |
| --- | --- |
| Время получения, UTC | 2026-10-22 23:12:17–23:12:19 |
| HTTP / тип | 200, `text/html`; строгая UTF-8 декодировка |
| Размер тела | 1 454 595 байт |
| SHA-256 тела | `70be3a71abaf2b85586553342f8ad9a0f65c42426c7b150cec89ae39eb56b169` |
| Начало заголовка дополнения | byte offset 189035 |
| Раздел навыка | byte range `[196585, 197176)` |

В этом разделе опубликованы изменения:

- Base damage уровня 1: 7–11 → 6–11
- Base damage уровня 20: 529–881 → 498–831
- Shotgun effect decay coefficient: 70% → 80%

Здесь коэффициент сохранён как заявленная величина. Его преобразование в
retained damage и топология попаданий требуют отдельных правил.

В пределах проверенного ответа added damage effectiveness 123% не найден.
Этот отрицательный результат относится к одному ответу, а не ко всем источникам.
Исходные байты, HTTP metadata и скрипты извлечения остаются в приватном
каталоге внешнего экспортёра `captures/20261023-0211-chromatic-addendum-witness/`.
Публичный репозиторий не содержит полного тела страницы.

## TLIDB и сохранённый каталог

Открытая при проверке [страница TLIDB Chromatic Shot](https://tlidb.com/en/Chromatic_Shot)
показывает ID 7007 и отметку SS14Season. Её строка уровня 20 указывает base
498–831, effectiveness 123% и shotgun coefficient 80%. Источник effectiveness
в этом сопоставлении — TLIDB; официальное дополнение его не подтверждает.

Сохранённый Compendium master содержит другой вариант: base 529–881,
effectiveness 131%, shotgun coefficient 70%. Первые и третьи величины совпадают
с дореформенными значениями в официальном дополнении. Это объясняет различие
публикаций, но не устанавливает версию данных конкретного персонажа.

## Граница применения

Дата публикации, отметка сезона и время загрузки не связывают профиль с
runtime/config revision. Дополнение даёт два опорных уровня; оно не задаёт
остальные строки таблицы. Нельзя масштабировать все уровни отношением баз
уровня 20 или выбирать вариант по совпадению с панелью.

Автоматическая привязка версии, effective level и отдельный post-20 growth
profile остаются открытыми. Ни raw damage, ни DPS этим свидетельством не меняются.
