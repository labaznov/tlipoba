# Источники итогового уровня Chromatic Shot

Проверено 2026-10-22 по сохранённым локальным данным. Исследование выявило три
кандидата прибавок уровня, но не установило единственный effective level.
Наблюдаемый уровень камня, lookup каталожной строки и итоговый уровень навыка
остаются разными величинами.

## Что сопоставлено

В сохранённом составе найдены две строки оружия с прибавкой уровня физических
навыков и один выделенный однопунктовый талант с прибавкой уровня заклинаний.
Оба признака присутствуют среди каталожных тегов Chromatic Shot. Это основание
проверять применимость строк, а не подтверждение всего правила их сложения.

У каждой строки оружия проверен полный native ID в собственном каталоге вещи,
единственный tier и попадание собственного roll в диапазон. Совпадение клиентского
текста использовано только как дополнительная проверка. Талант сопоставлен через
вычисляемый ID позиции/tier; один выделенный пункт подтверждается серверной копией.
Его идентификатор не становится из-за этого непосредственно наблюдаемым native ID.

Прежнее исследование замечало только одну строку оружия. Новый поиск обнаружил
вторую и талант, который не был виден при одном поиске текста исходного снимка.
Из этого не следует, что список всех возможных прибавок уже полон.

## Что осталось неизвестным

| Область | Наблюдение | Граница вывода |
|---|---|---|
| Уровень камня | Три именованных поля согласуются | Это наблюдаемый gem level, не effective level |
| Именованные схемы камня | В пяти проверенных схемах не найдено подтверждённое поле effective level | Остальные поля, opaque records и native tables не исключены |
| `SkillItemLevel` | В 36 типизированных парах значение отличается от `Level`; совпадений и пропущенных значений нет | Назначение поля неизвестно; несовпадение не исключает связь с другим видом уровня |
| Дополнительное дерево | Расшифрованы 115 пар ID/value | Нет каталожной привязки, значение пар неизвестно |
| Неоднозначные строки | Остаются неполные привязки вещей, призмы и utility pacts | Число найденных кандидатов не означает нулевых прибавок в этих строках |
| Версия | Есть сохранённые master/English members и их SHA | Совпадение с текущим клиентом не доказано |

В просмотренных сохранённых словах не найдено полного правила, которое одновременно
определяет matching level-bonus по тегам, сложение источников и действие обеих
оружейных строк. Эти условия нельзя подтвердить подгонкой к панели. Противоречие
профилей роста выше 20 также остаётся отдельной задачей:
[границы Help](help-skill-levels.md), [оператор с явными rates](../SKILL_GROWTH.md).

Отсутствие grant-строки в просмотренном каталожном домене описывает только эти
таблицы. Оно не исключает непроверенную клиентскую механику или неизвестный эффект.
Поэтому coverage различает найденные bound candidates и полноту поиска.

## Воспроизводимость и следующий шаг

Исходный снимок имеет SHA256
`da84d5c93bdf6c18c991d4758beb95a4e9db1b9fbb0260db10d10c778f56d645`.
Проверены 240 точных master/English slices с отдельными wrapper/member hashes.
Реальные уровни, роллы, native instance IDs и частные пути в репозиторий не перенесены.
Исходные файлы и cache сохранены; повторное исследование не читало игру или журнал.

Исследование helper 0430 исправлено в 0456: глобальное утверждение об отсутствии
поля заменено конечной областью проверки, сравнения уровней — типизированными
counts, неполные домены — явным unknown coverage. Preservation SHA вычисляются
потоком по 64 KiB; это ограничение памяти чтения, не максимального размера файла.
Пять синтетических проверок воспроизводят эти различия. SHA исправленного скрипта:
`6448dbc5c4c77cbc1f7a885805f2529e98bfb112dab7643aefbaa310a1f9e3a5`.

Диагностический resolver уже сохраняет кандидатов с source coordinate,
binding, scope и coverage в source-bound installed-level-candidates.
Точный native binding и вычисленный ID таланта различаются. Пока неизвестны правила и неполные домены,
итоговый уровень остаётся `null`. [Автоматические профили](../INSTALLED_PROFILES.md)
уже сохраняют каталожные поля на наблюдаемом уровне камня; [rawspell](../RAW_DAMAGE.md)
может принять неизвестный effective level с блокирующим level gate без выдуманного
числа. Числовой DPS этим не разрешается.

## Уточнение упоминания Skill Level в каталоге свойств героя

Проверено 2026-10-23. Один ранее отмеченный текст в `hero-trait/i18n/en`
описывает рост урона связанного навыка Burst при увеличении его уровня,
а не выдаёт прибавку уровня. Это tooltip по пути
`heroes[7ab70079-509b-523d-9c98-67e9e8694d48].hyperlinks[616].tooltip`.
Нельзя превращать это упоминание в ещё один кандидат `+# Skill Level`.

Независимая проверка точного UTF-8 member размером 502 492 байта подтвердила SHA256
`b0fec698dd6c38314a16ae054648d0d2e552b2d68ed0cb8da887b6156540c5eb`,
единственный текст с совпадением `skill level` без учёта регистра и этот контекст.
Master member проверен отдельно; указанные размеры не объявляются одним общим
бюджетом. Связь tooltip с принадлежащим игроку героем не установлена.
Это классификация конкретного текста, а не доказательство отсутствия других
прибавок в домене. Полнота источников, активация, effective level и DPS
остаются неподтверждёнными; поля producer и их буквальные счётчики не изменялись.
