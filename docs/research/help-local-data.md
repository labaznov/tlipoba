# Локальные источники игровой справки

Проверено 2026-10-21, офлайн. В сохранённых каталогах Compendium и конфигурационных снимках источник полных статей Help не найден. Название характеристики в модификаторе не подтверждает формулу или наличие справочного текста

Проверены 58 читаемых JSON каталогов и manifest с 6 331 путём. Отдельного набора Help/Glossary/Formula в этих данных не обнаружено. Это ограничение сохранённых источников, а не утверждение об отсутствии Help в клиенте

В конфигурации `Id=1021` найдены ссылки локализации `guide|des|1021`, `guide|des_pc|1021` и `guide|des_gamepad|1021`. Их перевод отсутствует; UI-аргументы похожи на tutorial. Соответствие статьям о расчётах не установлено, поэтому использовать 1021 как ID нужной статьи нельзя

Игровой процесс, бинарные контейнеры и установочные архивы при аудите не читались. Подробная инвентаризация и JSON pointers сохранены только в локальном игнорируемом исследовательском каталоге

Для извлечения Help из текущего клиента нужны подтверждённые имя таблицы, ID статьи, locale, текст и версия клиента. Захват должен сохранять исходный SHA-256 и не вызывать игровые функции. Имеющийся config lookup принимает известные числовые ID; готового извлечения справки и переводов в нём нет

Пока доступен [веб-индекс Help](https://tlidb.com/en/Help). Его датамайн помогает исследованию; побайтовое соответствие текущему клиенту не подтверждено. [Урон и крит](help-damage-critical.md), [конверсия и защита](help-defense-conversion.md), [уровни](help-skill-levels.md) фиксируют конкретные выводы и ограничения
