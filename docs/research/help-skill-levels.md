# Help: уровни навыка выше 20

Проверено 2026-10-21. [Skill Level на TLIDB](https://tlidb.com/en/Skill_Level) описывает остановку роста базового урона после уровня 20 и отдельный множитель за последующие уровни: 10% для 21–30, затем 8%, с перемножением. Это объясняет возможный плоский хвост **базового урона**; он не доказывает, что итоговый урон перестаёт расти. Правило не переносится автоматически на все параметры поддержки.

Есть конфликт версии: [официальная публикация](https://torchlight.xd.com/us/news/single?id=nezvlurrIS2B), чей текст посвящён The Frozen Canvas, описывает изменение на 12% и 10%. Заголовок сайта сейчас показывает другое название сезона; по нему нельзя датировать содержимое. [Журнал SS14](https://torchlight.xd.com/ss14pn/?lang=en) сам по себе не разрешил это расхождение.

До сверки с текстом клиента или версией конфигурации ни один профиль не выбирается по умолчанию. `levelValues` остаются параметрами экспортированного уровня; прибавки эффективного уровня от экипировки требуют отдельного восстановления. Готовый Spell DPS нельзя повторно умножать на найденный бонус уровней.

Для будущего расчёта нужны отдельные поля базового урона, эффективного уровня, профиля роста и происхождения профиля. Проверка плоского хвоста должна различать неизвестную таблицу и документированную остановку роста базы с отдельным множителем.
