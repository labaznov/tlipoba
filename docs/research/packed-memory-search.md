# Поиск контекста в смежных участках памяти

Проверено офлайн 2026-10-24, Windows, SS14. Это изменение внешнего
read-only экспортёра, а не новый результат импорта персонажа.

## Причина и изменение

Прежний поиск отказался до чтения содержимого: нижняя оценка числа вызовов
для трёх проходов по отдельным строкам карты превышала бюджет. Количество
строк само по себе не показывает, сколько чтений нужно для смежных байтов.

Finder v2 сначала полностью проверяет собственную ограниченную карту,
полученную прежним способом. Затем объединяет только точно смежные
читаемые приватные участки. Объединение сохраняет тот же набор байтов;
разрывы и исключённые области не заполняются. Проверка всей карты
предшествует первому чтению содержимого.

Лимиты сохранены: 100 000 логических вызовов, 20 ГиБ суммарного чтения,
8 ГиБ на проход и 30 секунд мягкого бюджета. Логический вызов карты
не равен одному нативному запросу её строки. Таймаут не прерывает
начатый системный вызов. Полная стоимость проверки кандидатов
не резервируется нижней оценкой трёх проходов.

Счётчики `scopePlan` используют фактический размер блока поиска,
а не всегда профильные 4 МиБ. До принятия всей карты поле равно `null`;
после принятия счётчики сохраняются и при последующем отказе.
Ошибочные аргументы API по-прежнему вызывают исключение без ответа.

Проверки строк, владельцев, целевой таблицы и неизвестных кандидатов,
лимит 512 КиБ на кандидата и остановка на первом пропуске сохранены.
Чтение через бывшую границу участков может обнаружить новые совпадения,
поэтому результаты v1 и v2 не обязаны совпадать.

## Проверка

Авторский RED-first цикл добавил 14 проверок: на прежнем коде они дали
три провала и 11 ошибок; прежняя 51 проверка прошла. Затем прошли
194 профильных теста, три проверки намеренных поломок и полный набор:
1405 тестов, 1403 прошли, два прежних пропуска.

Координатор независимо построил байтовые таблицы и выполнил 16 проверок.
При одинаковом бюджете в 400 вызовов прежний код отказался без чтений,
а v2 завершил синтетический поиск за 202 вызова. Контроль с разрывами
по-прежнему отказался до чтений. Отдельно проверены исключённые области,
поздняя ошибочная строка, фактический размер блока, первый пропуск,
прежние ограничения байтов и собственный пример ключа через границу.
Все 16 проверок прошли; это отдельная проверка от авторского набора.

Независимый Spec review функционально чист. Standards review не нашёл
блокирующих замечаний; существующий технический долг отмечен отдельно.
Уточнение документации о `null` принято без изменения поведения.

## Границы доказательств и следующий шаг

`scope.complete` означает три прохода по принятым строкам данной карты.
Это не доказывает полноту нативного адресного пространства, выбранного
игрока, атомарность или актуальность кэша. Только `scopePlan` не содержит
адресов; весь приватный ответ может содержать адрес найденной таблицы.

Сначала нужна одна отдельно проверенная
[диагностика карты без чтения содержимого](strict-memory-census.md).
Её нижняя оценка не доказывает, что карта следующего поиска останется
такой же. Решение об одной попытке поиска принимается отдельно;
автоматического повтора нет. Новый живой поиск, полный импорт и точный
DPS Carino этим офлайн-блоком ещё не подтверждены.
